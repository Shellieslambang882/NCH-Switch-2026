## 🔧 Troubleshooting

Having trouble? Try these common fixes:

### "Connection Failed" Error

1. Check your internet connection
2. Make sure you entered your API key correctly (it's case-sensitive)
3. Try restarting OwO-AI-Gateway
4. Check if your AI provider is having service issues

### App Doesn't Show Connected

1. Make sure your AI app supports custom gateways
2. Close and reopen your AI app after starting OwO-AI-Gateway
3. Check the OwO-AI-Gateway status dashboard for error messages

### Slow Performance

1. Close other resource-heavy programs
2. Try a smaller or faster model
3. Check your internet speed
